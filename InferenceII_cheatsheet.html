Confidence Intervals

Quick Reference
01 · The Shape

Confidence Interval

estimate ± margin of error
Every interval is a point estimate plus or minus a margin: a critical value times the standard error.
EXCEL
—
02 · Mean, σ Known

Z-Interval

x̄ ± zα/2 · σ/√n
Use the normal critical value when the population standard deviation σ is known.
EXCEL
=CONFIDENCE.NORM(α, σ, n)
03 · Mean, σ Unknown

t-Interval

x̄ ± tα/2 · s/√n
When σ is estimated by s, use the t-distribution with n−1 degrees of freedom (wider tails).
EXCEL
=CONFIDENCE.T(α, s, n)
04 · Proportion

p-Interval

p̂ ± zα/2 · √(p̂(1−p̂)/n)
The sample proportion is approximately normal, so a z critical value is used.
EXCEL
=NORM.S.INV(1−α/2)*SE
05 · Critical Values

z and t

z: 1.96 (95%), 1.645 (90%)
The multiplier that sets the confidence level. Use t when working from a sample standard deviation.
EXCEL
=NORM.S.INV(1−α/2) =T.INV.2T(α, df)
06 · Planning

Required Sample Size

n = (zα/2 σ / E)²
Solve the margin of error E for n. Always round up; use p̂ = 0.5 for a conservative proportion.
EXCEL
=(NORM.S.INV(1−α/2)*σ/E)^2
