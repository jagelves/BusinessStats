Quick Reference
01 · Categorical

Frequency Table

relative = fᵢ / n
Counts how many items fall in each category; the relative frequency is that count divided by the total n.
EXCEL
PivotTable · % of Column Total
02 · Visual

Bar Chart

categories with gaps
Displays category frequencies as separated bars — the gaps signal that the data is categorical.
EXCEL
Insert → Clustered Column
03 · How Many Classes

2ᵏ Rule & Sturges

2ᵏ ≥ n, k = ⌈1 + 3.322·log₁₀ n⌉
Two rules of thumb for choosing the number of classes when binning numerical data.
EXAMPLE
n = 50 → 6 or 7 classes
04 · Class Width

Width Formula

(Max − Min) / classes
Divide the range by the number of classes, then round up so every value fits in a class.
EXCEL
=(MAX(rng)-MIN(rng))/k
05 · Numerical

Frequency Table

assign a bin, then count
Give each value a class with a helper column, then count the values in each bin. Add a running total for cumulative %.
EXCEL
=IFS(...) · PivotTable
06 · Visual

Histogram

bins with no gaps
Like a bar chart but with the gap width set to 0 — touching bars show the data is numerical.
EXCEL
Clustered Column · Gap Width 0%
