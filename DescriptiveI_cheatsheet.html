Types of Data

BUSINESS STATISTICS · J. ALEJANDRO GELVES
Quick Reference
01 · Categorical

Nominal

labels with no order
Names or categories with no ranking. Summarized by counts and the mode. Ex: brand, gender, division.
EXCEL
=COUNTIF · PivotTable
02 · Categorical

Ordinal

ranked, unequal gaps
Ordered categories, but the gaps between ranks are not equal. Use the median and percentiles. Ex: satisfaction 1–5.
EXCEL
=MEDIAN · =QUARTILE.INC
03 · Numerical

Interval

equal gaps, no true zero
Differences are meaningful but ratios are not (zero is arbitrary). Use the mean and standard deviation. Ex: temperature, year.
EXCEL
=AVERAGE · =STDEV.S
04 · Numerical

Ratio

true zero, ratios valid
The strongest scale: a meaningful zero makes ratios valid, so every statistic applies. Ex: price, weight, sales.
EXCEL
=GEOMEAN · all functions
05 · Structure

Cross-Section vs Time Series

when it is collected
Cross-sectional data is captured at one point in time; time-series data is tracked over many periods.
EXAMPLE
2015 GDP vs 2000–2010 inflation
06 · Anatomy

Elements, Variables, Observations

how a data set is built
Elements are the entities (rows); variables are the characteristics collected (columns); an observation is one element's values.
EXAMPLE
1 row = 1 element
