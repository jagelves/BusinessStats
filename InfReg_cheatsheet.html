Quick Reference
01 · Is r Real?

Correlation Test

t = r√(n − 2) / √(1 − r²)
Tests whether the population correlation ρ differs from zero, with df = n − 2.
EXAMPLE
r = 0.5, n = 30 → t = 3.06, p ≈ 0.005
02 · Two Groups

Difference of Means

t = [(x̄₁ − x̄₂) − d₀] / SE
Compares two population means. SE depends on the design: unequal variances, equal (pooled) variances, or paired.
EXCEL
=T.TEST(arr1, arr2, tails, type)
03 · Same Subjects

Paired Test

t = (d̄ − d₀) / (s / √n)
Use when each observation is matched, such as before and after. df = number of pairs − 1. Removes person-to-person noise.
EXCEL
type: 1 paired · 2 equal · 3 unequal
04 · One Coefficient

Coefficient t-Test

t = bj / se(bj)
Tests H₀: βj = 0, whether one predictor matters holding the others fixed. df = n − k − 1.
EXCEL
Data → Data Analysis → Regression
05 · Whole Model

Joint F-Test

F = (SSR / k) / (SSE / (n − k − 1))
Tests whether all slopes are zero at once. A small Significance F rejects that null.
EXCEL
Regression output → Significance F
06 · Organize

ANOVA Table

MS = SS / df  ·  F = MSR / MSE
Regression has k df, residual n − k − 1, and total n − 1. SST = SSR + SSE.
EXCEL
Regression output → ANOVA
