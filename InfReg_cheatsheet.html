Quick Reference
01 · Is r Real?

Correlation Test

t = r√(n−2) / √(1−r²)
Tests whether a sample correlation reflects a real relationship; df = n − 2.
EXCEL
=(r*SQRT(n-2))/SQRT(1-r^2)
02 · Two Groups

Difference of Means

t = (x̄₁ − x̄₂ − d₀) / SE
Compares two population means. Choose paired, equal-variance, or unequal-variance.
EXCEL
=T.TEST(arr1, arr2, tails, type)
03 · Same Subjects

Paired vs Unpaired

paired: same subjects twice
Paired links each pair (before/after); unpaired compares independent groups.
EXCEL
type 1 paired · 2 equal · 3 unequal
04 · One Coefficient

Coefficient t-Test

t = bⱼ / se(bⱼ)
Tests whether a single predictor matters, holding the others fixed. df = n − k − 1.
EXCEL
Data Analysis → Regression
05 · Whole Model

Joint F-Test

F = (SSR/k) / (SSE/(n−k−1))
Tests whether all slopes are zero at once. A small Significance F rejects that.
EXCEL
Regression output → Significance F
06 · Predicting

Point & Interval

ŷ = α̂ + b₁x₁ + … + bₖxₖ
Plug values into the fitted line; the prediction interval widens it by t × sₑ.
EXCEL
=α̂ + b1*x1 + b2*x2 + ...
