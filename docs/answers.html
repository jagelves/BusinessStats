The minimum is \(0\), the first quartile is \(2\), second quartile is \(4\), third quartile is \(8\), and maximum is \(30\). \(30\) is an outlier since it is beyond \(Q_{3}+1.5 \times IQR\).

Quartiles are calculated with the location formula \(L_p = 1 + k(n-1)\). The sorted data is \(\{0,1,3,4,6,10,30\}\) with \(n = 7\):

  • \(L_{25} = 1 + 0.25(6) = 2.5 \Rightarrow Q_1 = 1 + 0.5(3-1) = 2\)
  • \(L_{50} = 1 + 0.50(6) = 4 \Rightarrow Median = 4\)
  • \(L_{75} = 1 + 0.75(6) = 5.5 \Rightarrow Q_3 = 6 + 0.5(10-6) = 8\)

In Excel we get the five point summary with =QUARTILE.INC():

=QUARTILE.INC(A:A, 0)   /* Minimum = 0  */
=QUARTILE.INC(A:A, 1)   /* Q1      = 2  */
=QUARTILE.INC(A:A, 2)   /* Median  = 4  */
=QUARTILE.INC(A:A, 3)   /* Q3      = 8  */
=QUARTILE.INC(A:A, 4)   /* Maximum = 30 */

The interquartile range is needed to determine if there are any outliers. The \(IQR = Q_3 - Q_1 = 6\). Since \(Q_3 + 1.5 \times IQR = 8 + 1.5(6) = 17\), everything beyond \(17\) is an outlier — so \(30\) is an outlier.

=QUARTILE.INC(A:A, 3) - QUARTILE.INC(A:A, 1)   /* IQR = 6  */
=QUARTILE.INC(A:A, 3) + 1.5 * 6                 /* UL  = 17 */

Since \(0.0028 < 0.01\), we reject the null at the \(1\%\) level.
