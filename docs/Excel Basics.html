15  Excel Basics

Below you will find a collection of basic Excel concepts along with a dictionary of the functions used throughout the descriptive statistics and regression chapters. Use the first sections to review how Excel organizes and references data, and use the dictionary as a quick reference for the functions that appear in each chapter.

Cells and References

A cell is the basic building block of a worksheet. Each cell is identified by its column letter and row number, such as A1 or C15. You store a value or a formula in a cell simply by typing into it. This is the Excel equivalent of assigning a value to an object.

When a formula refers to another cell, it uses a cell reference. References come in three forms:

  • Relative (A1) adjusts automatically when the formula is copied to another cell.

  • Absolute ($A$1) stays fixed when copied. The dollar signs lock both the column and the row.

  • Mixed ($A1 or A$1) locks only the column or only the row.

For example, =A1*2 multiplies the value in A1 by two. Pressing F4 while editing a reference cycles through the relative, absolute, and mixed forms.

Ranges

A range is a group of adjacent cells, written as the top-left cell, a colon, and the bottom-right cell. For example, A1:A10 is a single column of ten cells, and A1:C10 is a rectangular block. A range is the Excel equivalent of a vector — a list of values that most statistical functions take as an input.

You can reference an entire column with A:A or an entire row with 1:1. To give a range a memorable name, select it and go to Formulas → Define Name; you can then use the name in formulas instead of the cell addresses.

Worksheets and Tables

Data in Excel is stored in a worksheet in a tabular format, much like a data frame. Columns represent variables and rows represent observations, with the first row typically holding the headers. For a cleaner structure, select your data and press Ctrl + T (or go to Insert → Table) to convert the range into an Excel Table. Tables make it easy to sort, filter, and refer to columns by name.

The Data Analysis ToolPak

Some analyses — such as regression — require the Analysis ToolPak, an add-in that ships with Excel but is turned off by default. Enabling an add-in is the Excel equivalent of installing and loading a package. To enable it on Windows, go to File → Options → Add-ins → Manage: Excel Add-ins → Go, check Analysis ToolPak, and click OK. On a Mac, use Tools → Excel Add-ins. Once enabled, the ToolPak appears under Data → Data Analysis.

Importing Data

To import a CSV file, use File → Open and select the file, or go to Data → Get Data → From Text/CSV for more control over how the columns are separated. To preview large data sets, freeze the header row with View → Freeze Panes, and use Ctrl + ↓ or Ctrl + End to jump to the last observation.

Formulas and Functions

Every calculation in Excel begins with an equals sign (=). A function relates an input (its arguments) to an output. For example, the SUM function takes a range of numeric values and returns their total:

=SUM(A2:A5)

Arguments are separated by commas, and some are optional. Many functions accept a criteria argument that filters the data, such as =AVERAGEIF(A2:A100, ">=1", B2:B100). A few calculations — like a conditional variance — must be entered as array formulas. In older versions of Excel you complete these by pressing Ctrl + Shift + Enter instead of just Enter. If a formula cannot be evaluated, Excel returns an error such as #DIV/0!, #VALUE!, #N/A, or #REF!.

Data Types

The main data types in Excel are number, text, logical, date, and error.

  • Number includes integers and decimals. Numbers are right-aligned in a cell by default.

  • Text represents labels or strings and is left-aligned by default.

  • Logical values are TRUE or FALSE, usually produced by a comparison.

  • Date and time values are stored as serial numbers counting the days since January 1, 1900, which is why dates can be added and subtracted.

  • Error values are the result of an invalid operation, such as dividing by zero.

Comparison and Logical Operators

Comparison operators return a logical value (TRUE or FALSE). The primary operators are = (equal to), <> (not equal to), > (greater than), < (less than), >= (at least), and <= (at most). They are frequently combined with the IF, AND, OR, and NOT functions. When used inside a criteria argument, an operator is written as text in quotes, for example ">=1" in a COUNTIF or AVERAGEIF formula.

15.1 Dictionary of Functions

The remainder of the chapter lists the Excel functions and tools used in the book, grouped by the chapter in which they first appear.

General Purpose

  • =SUM(range) adds all of the numbers in a range.

  • =COUNT(range) counts the cells that contain numbers, while =COUNTA(range) counts all non-empty cells.

  • =MIN(range) and =MAX(range) return the smallest and largest values in a range.

  • =ABS(number) returns the absolute value of a number.

  • =SQRT(number) returns the square root of a number.

  • =IF(test, value_if_true, value_if_false) returns one of two values depending on whether a condition is met.

  • =AND(...), =OR(...), and =NOT(...) combine or reverse logical conditions.

Tables and Charts (Descriptive Stats II)

  • PivotTable (Insert → PivotTable) automatically summarizes and counts data, making it the primary tool for building frequency and relative frequency distributions.

  • =IFS(test1, value1, test2, value2, ...) checks multiple conditions in order and returns the value for the first one that is true. It is used to assign each numerical observation to its class (bin) when building a frequency distribution.

Measures of Central Location (Descriptive Stats III)

  • =AVERAGE(range) calculates the mean of a range of numbers.

  • =MEDIAN(range) calculates the median.

  • =MODE(range) returns the single most frequent value, while =MODE.MULT(range) returns all modes when the data is multimodal.

  • =SUMPRODUCT(array1, array2) multiplies corresponding values in two ranges and sums the results. Dividing by =SUM(weights) gives the weighted mean.

  • =GEOMEAN(range) calculates the geometric mean. For rates of change, apply the function to the growth factors (1 + r) and subtract one at the end.

  • =AVERAGEIF(range, criteria, average_range) calculates the mean of the values that meet a given condition.

Measures of Dispersion (Descriptive Stats IV)

  • =COUNTIF(range, criteria) counts the number of cells that meet a condition.

  • =MINIFS(min_range, criteria_range, criteria) and =MAXIFS(max_range, criteria_range, criteria) return the minimum and maximum values filtered by one or more conditions.

  • =VAR.S(range) calculates the sample variance; =VAR.P(range) calculates the population variance.

  • =STDEV.S(range) calculates the sample standard deviation (the square root of the sample variance); =STDEV.P(range) calculates the population standard deviation.

  • =VAR(IF(criteria_range="condition", value_range)) and =STDEV(IF(criteria_range="condition", value_range)) calculate a conditional variance and standard deviation. Excel has no native VARIF or STDEVIF, so these are entered as array formulas.

  • Coefficient of Variation has no dedicated function; compute it as =STDEV.S(range) / AVERAGE(range).

  • Sharpe Ratio also has no dedicated function; compute it as =(AVERAGE(range) - rf) / STDEV.S(range), where rf is the risk-free rate.

Measures of Shape and Position (Descriptive Stats V)

  • =PERCENTILE.INC(array, k) returns the \(k\)th percentile using the inclusive method \(L_p = 1 + k(n-1)\), where k is a decimal between 0 and 1. =PERCENTILE.EXC(array, k) uses the exclusive method \(L_p = k(n+1)\).

  • =QUARTILE.INC(array, quart) returns the five-point summary. The quart argument takes the values 0 (minimum), 1 (\(Q_1\)), 2 (median), 3 (\(Q_3\)), and 4 (maximum). The IQR is =QUARTILE.INC(array, 3) - QUARTILE.INC(array, 1).

  • =STANDARDIZE(x, mean, std_dev) calculates the z-score of a value. It can also be computed manually as =(x - AVERAGE(range)) / STDEV.S(range).

  • =SKEW(range) calculates the skewness using the Fisher-Pearson standardized moment coefficient.

  • =KURT(range) calculates the excess kurtosis. A positive value indicates heavy tails (leptokurtic) and a negative value indicates light tails (platykurtic).

Measures of Association (Regression I)

  • =COVARIANCE.S(array1, array2) calculates the sample covariance between two variables; =COVARIANCE.P(array1, array2) calculates the population covariance.

  • =CORREL(array1, array2) calculates the correlation coefficient, which is always between \(-1\) and \(1\).

  • =CORREL(array1, array2)^2 calculates the coefficient of determination \(R^2\) by squaring the correlation coefficient. Excel has no standalone \(R^2\) function for two variables.

Regression (Regression II)

  • Data Analysis ToolPak → Regression is the primary tool for estimating regression models. It returns the coefficients, \(R^2\), adjusted \(R^2\), standard error, and the ANOVA table in a single output.

  • =SLOPE(y_range, x_range) calculates the slope \(\hat{\beta}\) of a simple regression line.

  • =INTERCEPT(y_range, x_range) calculates the intercept \(\hat{\alpha}\) of a simple regression line.

  • =FORECAST.LINEAR(x, y_range, x_range) returns the predicted value of \(y\) for a given value of \(x\).

  • =RSQ(y_range, x_range) returns the \(R^2\) of a simple regression.

  • =STEYX(y_range, x_range) returns the residual standard error \(s_e\) of a simple regression.
