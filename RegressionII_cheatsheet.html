The Regression Line

BUSINESS STATISTICS · J. ALEJANDRO GELVES
Quick Reference
01 · The Line

Regression Line

ŷ = α̂ + β̂x
The best linear fit between two variables. Estimate it in one step with the Data Analysis ToolPak.
EXCEL
Data → Data Analysis → Regression
02 · Steepness

The Slope

β̂ = sxy / s2x
How much y changes, on average, for a one-unit increase in x.
EXCEL
=SLOPE(y_range, x_range)
03 · Starting Point

The Intercept

α̂ = ȳ − β̂x̄
The predicted value of y when x equals zero.
EXCEL
=INTERCEPT(y_range, x_range)
04 · Goodness of Fit

Coefficient of Det.

R2 = SSR / SST
The percent of the variation in y explained by the model. Ranges 0 to 1.
EXCEL
=RSQ(y_range, x_range)
05 · Typical Error

Residual Std. Error

se = √[ SSE / (n − k − 1) ]
The average distance of the data points from the regression line.
EXCEL
=STEYX(y_range, x_range)
06 · Prediction

Forecasting

ŷ = α̂ + β̂x
Plug an x value into the fitted line to predict y.
EXCEL
=FORECAST.LINEAR(x, y_range, x_range)
