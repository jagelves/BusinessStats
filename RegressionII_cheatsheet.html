The Regression Line

BUSINESS STATISTICS · J. ALEJANDRO GELVES
Quick Reference
01 · The Line

Regression Line

ŷ = α^ + β^x
The line that minimizes the sum of squared errors between the observed and predicted values of y.
EXCEL
=LINEST(y, x, TRUE, TRUE)
02 · Steepness

The Slope

β^ = sxy / sx²
Average change in y for a one-unit increase in x.
EXCEL
=INDEX(LINEST(y, x, TRUE, TRUE), 1, 1)
03 · Starting Point

The Intercept

α^ = ȳ − β^x̄
The predicted value of y when x equals zero.
EXCEL
=INDEX(LINEST(y, x, TRUE, TRUE), 1, 2)
04 · Goodness of Fit

Coefficient of Det.

R² = SSR / SST
Share of the variation in y explained by the model. SST = SSR + SSE, so R² is between 0 and 1.
EXCEL
=INDEX(LINEST(...), 3, 1)
05 · Many Predictors

Multiple Regression

ŷ = β^₀ + β^₁x₁ + ⋯ + β^kxk
Predicts y with k independent variables. Each coefficient is the change in y for a one-unit change in its variable.
EXCEL
=LINEST(y, HSTACK(x1, x2), TRUE, TRUE)
06 · Explained vs Noise

F-Statistic

F = MSR / MSE
= (SSR / k) / (SSE / (n − k − 1))
Explained variation per variable compared with the noise left over. Values far above 1 point to a real pattern.
EXCEL
=INDEX(LINEST(...), 4, 1)
07 · Penalized Fit

Adjusted R²

R̄² = 1 − (1 − R²)(n − 1) / (n − k − 1)
Adjusts R² for the number of variables, so adding weak predictors is not rewarded.
EXAMPLE
R² = 0.96, n = 5, k = 2 → R̄² = 0.92
08 · Typical Error

Residual Std. Error

se = √[ SSE / (n − k − 1) ]
Typical distance of the data points from the regression line, in the units of y.
EXCEL
=INDEX(LINEST(...), 3, 2)
09 · Categories

Dummy Variables

d = 1 if in the category, 0 otherwise
With m categories use m − 1 dummies. The intercept is the baseline mean; each coefficient is a gap from it.
EXCEL
=IF(A2="Sam", 1, 0)
