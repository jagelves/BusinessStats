Quick Reference
01 · Center

Expected Value

E(x) = μ = Σ x f(x)
The long-run average of a random variable, weighting each value by its probability.
EXCEL
=SUMPRODUCT(x_range, p_range)
02 · Spread

Variance

var(x) = E(x²) − [E(x)]²
The average squared deviation from the mean. Its square root is the standard deviation.
EXCEL
=SUMPRODUCT((x_range − μ)^2, p_range)
03 · Equally Likely

Discrete Uniform

f(x) = 1 / n
Each of the n possible values is equally likely, like the faces of a fair die.
EXAMPLE
P(die shows 6) = 1/6
04 · Successes in n Trials

Binomial

f(x) = C(n, x) pˣ (1 − p)n − x
Successes in n independent trials with the same probability p. E(x) = np, var(x) = np(1 − p).
EXCEL
=BINOM.DIST(x, n, p, FALSE)
05 · Without Replacement

Hypergeometric

f(x) = C(r, x) C(N − r, n − x) / C(N, n)
Successes in a sample of n drawn without replacement from N items, r of which are successes.
EXCEL
=HYPGEOM.DIST(x, n, r, N, FALSE)
06 · Counts in an Interval

Poisson

f(x) = μˣ e−μ / x!
Number of occurrences in an interval of time or space. Mean and variance both equal μ.
EXCEL
=POISSON.DIST(x, μ, FALSE)
