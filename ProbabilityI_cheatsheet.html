Probability Rules

BUSINESS STATISTICS · J. ALEJANDRO GELVES
Quick Reference
01 · Equally Likely

Classical Method

P(A) = outcomes in A / outcomes in S
Use only when every outcome in the sample space is equally likely.
EXAMPLE
P(red card) = 26/52 = 0.5
02 · From Data

Relative Frequency

P(A) ≈ times A occurred / trials
Estimates the probability from past data. The estimate improves as the number of trials grows.
EXCEL
=COUNTIF(rng, "Late") / COUNTA(rng)
03 · Any Method

Basic Requirements

0 ≤ P(A) ≤ 1  ·  ΣP(xᵢ) = 1
Every assignment must satisfy both, including subjective ones. 0 and 1 mean certainty; values in between mean uncertainty.
EXAMPLE
P(success) = 0.35, P(failure) = 0.65
04 · Not A

Complement Rule

P(Aᶜ) = 1 − P(A)
The chance an event does not occur. Often easier to compute than the event itself.
EXAMPLE
P(not heart) = 1 − 13/52 = 39/52
05 · A or B

Addition Rule

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
Subtract the overlap so it is not counted twice. If A and B are mutually exclusive, P(A ∩ B) = 0.
EXAMPLE
heart or face: 13/52 + 12/52 − 3/52 = 22/52
06 · A and B

Multiplication Rule

P(A ∩ B) = P(A | B) · P(B)
P(A | B) = P(A ∩ B) / P(B)
The chance both occur. If A and B are independent, P(A ∩ B) = P(A) · P(B).
EXAMPLE
two aces: (4/52)(3/51)
07 · Scenarios

Total Probability

P(A) = Σ P(A | Bᵢ) · P(Bᵢ)
Adds the chance of A across scenarios Bᵢ that are mutually exclusive and exhaustive.
EXAMPLE
(0.5)(0.02) + (0.3)(0.03) + (0.2)(0.05) = 0.029
08 · Updating

Bayes' Theorem

P(A | B) = P(B | A) · P(A) / P(B)
Turns a prior P(A) into a posterior after observing evidence B. Find P(B) with the law of total probability.
EXAMPLE
positive test: 0.01 → 0.0876
09 · Counting

Counting Rules

n!  ·  C(n, x) = n! / [(n − x)! x!]
P(n, x) = n! / (n − x)!
Count outcomes without listing them. Combinations ignore order; permutations respect it.
EXCEL
=FACT(n) · =COMBIN(n, x) · =PERMUT(n, x)
